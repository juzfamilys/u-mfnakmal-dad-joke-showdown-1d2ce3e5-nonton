## The joke

> I changed the Wi-Fi password to 'DadJokes123', so now every time my kids log in, they have to type that I'm funny.

## How to run

```sh
python3 main.py
```

This writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validating first that it is a single line of 1–200 characters. Pure Python standard library, deterministic — the same bytes on every run.
